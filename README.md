# 🌐 Macedo Farias

## 📋 Sobre o Projeto

O Site Macedo Farias é uma landing page institucional desenvolvida para divulgação de produtos e atendimento comercial.

O objetivo do projeto foi criar uma presença digital simples, moderna e funcional, permitindo que clientes visualizem os produtos disponíveis e entrem em contato diretamente pelo WhatsApp para solicitar informações ou realizar pedidos.

O desenvolvimento foi realizado utilizando tecnologias Front-End fundamentais e contou com o apoio de ferramentas de Inteligência Artificial para acelerar a construção da interface e otimizar o processo de desenvolvimento.

---

## 🚀 Tecnologias Utilizadas

* CSS3
* JavaScript

## 🎯 Objetivo do Projeto

Desenvolver uma página institucional simples e responsiva para divulgação de produtos e captação de clientes através do WhatsApp.

O projeto teve como foco praticar:

* Estruturação de páginas web
* Organização de conteúdo visual
* Responsividade
* Integração com WhatsApp
* Publicação de aplicações na web

---

## ⚙️ Funcionalidades

### Catálogo de Produtos

* Exibição visual dos produtos disponíveis
* Navegação simples e intuitiva

### Integração com WhatsApp

Ao selecionar um produto, o usuário é direcionado para uma conversa no WhatsApp, facilitando o contato comercial.

### Design Responsivo

* Compatível com dispositivos móveis
* Compatível com tablets
* Compatível com desktops
